# Harshini — AI automation engineer

A portfolio board of the AI systems I build in n8n: a voice agent that books, an AI hiring
pipeline, a lead qualifier with retrieval and a human approval gate, and four smaller agents
in service. Each one opens to the chain it actually executes — trigger, steps, gates, and the
fail-safe branch.

**Live:** https://harshinilingampally.github.io

Static HTML, CSS and JavaScript. No build step, no framework, no dependencies.

```
index.html        the page
assets/board.css  the visual system
assets/board.js   row disclosure, keyboard operation, the reel player
media/            the reels and their posters
```

Run it locally with any static server:

```bash
python -m http.server 8787
```

Client names, candidate details and workflow internals are deliberately withheld throughout.
Every figure on the board was measured on a system that has run.
